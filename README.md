# МатОлимп — «Duolingo для олимпиадной математики»

Приложение для подготовки к математическим олимпиадам (ВсОШ и др.). Полностью на русском, бесплатное. Основной рынок — Android / RuStore, есть веб-версия.

## Что внутри

- **Темы курса** (14 тем): индукция, принцип Дирихле, делимость, инварианты, комбинаторика, графы, неравенства, игры, логика, геометрия, текстовые задачи, разрезания, диофантовы уравнения, алгебра — подробная теория «от топ-преподавателей» + задачи.
- **Подготовка** к муниципальному и региональному этапам.
- **Разбор олимпиады** — полные разборы всех задач туров ВсОШ по годам:
  - Региональный этап **2016–2026** (11 лет, оба тура, 9–11 классы).
  - Муниципальный этап (Москва) **2021–2024** (7–9 классы).
  - Каждая задача: условие → официальное решение → классификация по приёму (14 приёмов).
- **~528 реальных олимпиадных задач**, ответы сверены по официальным решениям.
- Гибридная проверка: закрытые (авто-проверка числового ответа) + открытые (доказательство с самооценкой).
- Геймификация: XP, уровни, серии (streak).
- **AI-объяснение** решения (RouterAI / DeepSeek), через прокси-воркер (ключ не в клиенте).

## Структура репозитория

```
/                — Android-приложение (Kotlin + Jetpack Compose + Room)
  app/src/main/assets/seed.json   — банк контента (темы, теория, задачи)
/web             — веб-версия (React + Vite + KaTeX), деплой на Vercel
/proxy           — Cloudflare Worker-прокси для AI (держит ключ RouterAI)
```

## Android — сборка

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Требуется JDK 21, Android SDK (build-tools 34/35). Конфиг AI — в `local.properties` (см. `proxy/README.md`); в репозиторий не попадает.

**Стек:** Kotlin, Jetpack Compose (Material3), Room, Navigation Compose, JLaTeXMath (рендер LaTeX на Canvas, без WebView).

## Веб — запуск

```bash
cd web
npm install
npm run dev
```

**Стек:** React + Vite + KaTeX. Использует тот же `seed.json`, что и Android.
